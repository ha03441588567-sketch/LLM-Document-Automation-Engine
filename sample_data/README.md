# Sample data

Drop test invoices/logistics documents here (PDF/PNG/JPG) to test the
`/extract` endpoint locally. These files are git-ignored — don't commit
real company documents to a public repo.

Get free sample invoices for testing from datasets like:
- CORD dataset (receipts): https://huggingface.co/datasets/naver-clova-ix/cord-v2
- FUNSD (forms): https://guillaumejaume.github.io/FUNSD/
